# HealthConnect

HealthConnect is a healthcare management system that helps users find doctors based on specialization and book appointments easily. The system provides a simple interface for patients and an admin dashboard for managing appointments efficiently.

# Features

- Doctor specialization search
- Doctor profile display
- Appointment booking
- Appointment cancellation
- Admin dashboard for managing appointments
- Admin acceptance and rejection of appointment requests

# Technologies Used

- Java Swing
- MySQL
- Eclipse IDE
- GitHub
